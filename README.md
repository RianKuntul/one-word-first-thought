Entry for the make.fun "One Word, First Thought" bounty: exactly one word — the first word that comes to mind, no topic, no explanation, no second draft. The judge compares words pairwise on which is more interesting, so this entry bets on surprise, vividness, and a spark of wit over safe filler.

## Run

```sh
node main.ts
```

Writes the entry word to `entry.txt` under `$MAKEFUN_OUTPUT_DIR` (defaults to `/output`).

## The entry

> **defenestration**

One word, one scene: somebody, a window, and a very bad day.
